Descarga del proyecto final

El proyecto final del curso es una plataforma académica terminada: cinco microservicios con seguridad JWT, comunicación entre servicios, documentación en Swagger, pruebas automatizadas y despliegue con Docker. Descárguela o clónela para analizarla con las guías del curso.

Repositorio del proyecto

El proyecto se encuentra disponible en la siguiente ruta de GitHub:

https://github.com/alejandroria94/proyecto-s3.git

El repositorio contiene el código completo, el README.md con las instrucciones de ejecución y la carpeta instrucciones/ con las guías de análisis de cada módulo y de cada extensión.

¿Qué debe hacer el estudiante?

  1. Ingresar al repositorio del proyecto base en GitHub.
  2. Descargar el proyecto como archivo ZIP o clonarlo con Git.
  3. Abrir la solución en su entorno de desarrollo.
  4. Compilar y ejecutar los cinco servicios siguiendo el README.md, y ejecutar las pruebas con mvn test.
  5. Recorrer las guías de análisis en el orden indicado en las instrucciones, ejecutar sus verificaciones y responder sus preguntas.
Recomendación: clone el repositorio con Git: así puede usar el historial y las búsquedas del IDE para ubicar rápidamente los archivos que mencionan las guías.

Comando sugerido para clonar el repositorio

git clone https://github.com/alejandroria94/proyecto-s3.git

Después de clonar el repositorio, ubíquese en la carpeta del proyecto, siga el README.md para ejecutarlo y continúe con las guías de análisis.
